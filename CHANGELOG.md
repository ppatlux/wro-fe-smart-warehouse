# Changelog

All changes to the kit are listed here, newest first.

## Version numbers

Versions use the format **x.y.z**:

- **z** – a small fix. Parts still fit together with the previous version.
- **y** – a part changed shape. The entry lists which parts to reprint.
- **x** – a new season or a rules change.
